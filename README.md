# 集团作战地图（demo）

在世界地图上展示 KA 集团子公司的分布和合作阶段。纯前端项目：React 18 + Vite + TypeScript + ECharts，没有后端。

窗口和全屏展示的是同一套界面（1920×1080 画布等比缩放），右上角「全屏展示」进入全屏，Esc 退出。

## 启动

```bash
./start.sh        # 正式运行：打包后启动，端口 5188（监听 0.0.0.0），演示用这个
./start.sh dev    # 开发模式：改代码自动刷新，首次加载较慢
./start.sh stop   # 停止
```

访问 `http://<服务器IP>:5188/demo1` 、`/demo2` 或 `/demo3`。`http://<服务器IP>:5188/` 是方案列表，列出所有 demo。

一个 demo 一个地址，在 `frontend/src/main.tsx` 的 `DEMOS` 里登记；各 demo 的代码和样式分开加载，公司数据和底图共用。

## 两个 demo

| 地址 | 内容 | 代码 |
|---|---|---|
| `/demo1` | 地图为主：可以逐级放大，看子公司分布和合作情况。有浅色（照 demo2 的白底风格，默认）和深色（原来的作战沙盘）两种风格，标题栏右侧按钮切换，浏览器会记住上次的选择；浅色样式在 `src/index.css` 末尾，地图配色在 `WorldMap.tsx` 的 `PALETTES`。下面「界面怎么看」「地图怎么看」两节说的是它 | `src/App.tsx`、`src/views/`、`src/components/` |
| `/demo2` | 照 `data/作战地图.jpg` 复刻的一屏四块（白底浅色风格）：集团布局概览（可拖动、滚轮缩放到城市级，点城市联动筛选其它三块）、各工厂/业务单元作战计划、产品布局、关键项目推进表 | `src/demo2/` |
| `/demo3` | 左侧目录 + 右侧内容的后台式页面：总览、集团布局（布局概览、子公司清单）、作战计划（各工厂作战计划、关键项目推进）、产品布局。目录的分组可以展开 / 折叠，整个目录可以收起成一列图标；表格可以搜索、筛选、排序、翻页，点一行看公司详情。当前页面记在地址里（如 `/demo3#/plan`） | `src/demo3/`（数据计算和地图复用 demo2 的） |

demo2 的数据照抄图片，写在 `src/demo2/battleData.ts`，不读 CRM 数据，也没有集团切换。图片上地图标的是中国 4 个、东南亚 2 个、欧洲 1 个、北美 1 个工厂，表格只列了 5 个，所以补了武汉、成都、泰国三个工厂；越南、欧洲、北美工厂的城市（胡志明市、斯图加特、底特律）也是这里定的。

demo2 的地图：缩小时按大区显示（欧洲/中国/东南亚/北美），放大到城市级后每个城市一根针；点城市（或大区、左上角快捷定位）选中这里，作战计划、产品布局、项目推进三张表只显示相关的工厂（板块标题右侧显示「已筛选」，再点一次、点地图空白处、点 × 或「全球」取消）；地图上点击不弹窗。点作战计划或项目表的一行，弹出工厂信息（含相关产品线和关键项目）。`src/demo2/derive.ts` 和 `OverviewMap.tsx` 现在只给 demo3 用。

两个 demo 共用取数和集团切换（`src/useGroupData.ts`），在一个里切换了集团，另一个打开时也是这个集团。

## 界面怎么看（demo1）

看板回答三个问题：哪些地方还没合作上、合作情况怎么样、子公司分布在哪。地图是主体，其它模块浮在地图上，只统计「当前范围」（全球 / 海外的某个大区 / 某个国家 / 某个省）里的公司。

统计口径（代码在 `src/stats.ts`，面板和标牌共用）：**合作率** = 已合作 ÷ 子公司；**待突破** = 子公司 − 已合作。

看板一次只看一个集团。数据里有多个集团（公司的 `group` 字段）时，标题栏左侧出现下拉框；切换后地图回到全球，所有数字换成该集团的。上次看的集团记在浏览器里。只有一个集团时不显示下拉框；集团超过 8 个时下拉框里可以输入文字搜索。

模块：

- 标题下的指标条：子公司、已合作、合作率、待突破。
- 左列：合作阶段（四个阶段各多少家）、目标产品（每种产品的已合作 / 涉及的子公司）。一家公司可以有多个目标产品，在每个产品里各算一次，所以各产品的家数加起来会超过子公司总数。
- 左上的按钮：全球、中国，以及数据里出现的海外大区（公司的 `region` 字段，如亚洲、东南亚、欧洲、北美）。点击后地图飞到能看全该大区公司的位置，面板的数字一起切换。数据里多出一个大区，按钮会自动多一个。
- 左上「当前范围」可以点回上一级；点国家、省的标牌会切换范围；用滚轮缩小到上一级时范围自动回退。
- 图例（底部）只决定地图上画哪些阶段的公司，不影响面板的数字。

## 地图怎么看

类似房源地图的逐级汇总，放大后自动切换到下一级。地图只精确到城市，公司明细在右侧列表里看：

| 放大倍数 | 显示 |
|---|---|
| 小于 2.2 | 按国家汇总（每个国家单独一块标牌）；「全球」是 0.6 倍 |
| 2.2 ～ 6 | 国内按省份汇总，海外仍按国家 |
| 6 ～ 48（最大） | 按城市汇总 |

- 地图上的标记是「光柱标牌」：地面一个落点，一根光柱，顶端的标牌写地名和「已合作 / 子公司」（如「湖南 10/207」）。光柱越高子公司越多。
- 整块标牌只用一种颜色：这个地方走得最远的阶段的颜色（同图例）。全部未合作的是灰色。
- 点击国家、省份的标牌：放大到下一级。点击城市的标牌：右侧列出该市的全部公司，再点某家公司看详情。
- 滚轮滚两格放大一倍，以鼠标所在位置为中心。
- 标牌会互相压住时，先把光柱加高错开；省、市的标牌还错不开就合并为「某地等 N 地」，点击继续放大；国家的标牌不合并。
- 标牌和底图只会把同一个地名写一次；名字长的国家在标牌上用简称（沙特、印尼、哈萨克）。
- 图例筛掉部分阶段后，标牌只写显示出来的公司数。

## 更新数据

1. 用新的 Excel 替换 `data/KA集团子公司_补充模拟数据.xlsx`（表头保持一致）。要加一个集团，就在 `data/` 下再放一个 `KA集团子公司_xxx.xlsx`，「所属集团」列填集团名。
2. 重新生成并启动：

```bash
cd frontend
npm run data      # 读 data 下所有 KA集团子公司_*.xlsx；也可以指定文件：npm run data -- <某个.xlsx> …
cd .. && ./start.sh
```

清洗规则（`scripts/clean-data.mjs`）：

- 按表头名称取列，必须有「名称」「注册地址」两列。
- 同名公司只保留第一行（原表有 327 家重复导入）。
- 从注册地址识别国家、省、市，县级并入所属地级市；识别不出的行会跳过，并在命令行里列出来。
- 经纬度用表里的「经度」「纬度」；没有时用城市中心坐标。
- 目标产品可以有多个：单元格里用顿号、逗号、分号或斜杠隔开（如「激光器、光连接」），清洗后是一个列表。
- 演示用的补充：原始表里每家只填了一个产品，清洗时让约 30% 的公司多出一两个（从同一张表出现过的产品里按公司名固定挑选）。对接真实数据时把 `clean-data.mjs` 里的 `mockMulti: true` 去掉。
- 目标产品为空或「不适用」的（补充模拟数据时的占位，共 331 家），按公司名固定分到激光设备、激光器、光连接、PCD微钻四种里，同一家公司每次结果相同。
- 海外公司的大区（`region`）按国家对照表得到（`clean-data.mjs` 里的 `AREA`）：北美、南美、欧洲、东南亚、亚洲（中国和东南亚以外的亚洲国家）、非洲、大洋洲；表里没有的国家归「海外」。
- 阶段只认 4 个：未合作、规划中、商机开发、已合作，其它值按「未合作」；预计规模为空时按 0。

## 对接真实接口

前端通过 `src/api.ts` 的 `fetchCompanies()` 取数据，默认请求 `/mock/companies.json`，页面每 60 秒自动重新请求一次。

1. 复制 `frontend/.env.example` 为 `frontend/.env`，把 `VITE_COMPANIES_URL` 改成真实接口地址，重新打包。
2. 接口返回的格式和下面不一样时，只在 `fetchCompanies()` 里做转换，其它代码不用改。

```json
{
  "updatedAt": "2026-11-23",
  "stages": ["未合作", "规划中", "商机开发", "已合作"],
  "companies": [{
    "id": "…", "name": "…", "group": "三一集团有限公司",
    "country": "中国", "province": "湖南", "city": "长沙", "region": "华中",
    "stage": "已合作", "products": ["激光器", "光连接"], "owner": "王五", "next": "…",
    "scale": 300, "address": "…", "website": "", "coord": [112.94, 28.23]
  }]
}
```

接口和页面不在同一个地址时，接口那边需要允许跨域访问。

## 开发

```bash
cd frontend
npm test          # 清洗脚本和统计口径的测试
npm run build     # 类型检查 + 打包
```

读 Excel 用的是 SheetJS（`xlsx`），从它的官方地址 cdn.sheetjs.com 安装，所以首次 `npm install` 需要能访问外网。
不要换成 exceljs：CRM 导出的表每列都带"整列到第 1048576 行"的数据验证，exceljs 读它会卡死，流式读取又会把部分汉字读成乱码。

底图是开源数据（Natural Earth + ECharts 中国地图），正式使用需要换成带审图号的标准地图。
